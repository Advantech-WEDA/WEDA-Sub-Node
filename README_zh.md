# Weda SubNode SDK

專為 IoT 邊緣設備開發的完整 .NET SDK,提供設備連接、資料採集、處理與雲端整合。

## 快速開始

### 方式 1: Dev Container（推薦）

立即使用預先配置好的開發環境：

1. 安裝 [Docker Desktop](https://www.docker.com/products/docker-desktop) 和 [VS Code](https://code.visualstudio.com/)
2. 安裝 [Dev Containers 擴充套件](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)
3. 用 VS Code 開啟此專案
4. 按 `Ctrl + Shfit + P` → 選擇 `Dev Containers: Reopen in Container`

所有工具都已預先安裝：.NET SDK、專案範本以及所有開發工具！

**[了解更多 Dev Container 資訊](.devcontainer/README.md)**

## 功能特色

- **多協定支援** - Modbus TCP/RTU, MQTT
- **資料處理管道** - 校準、濾波、轉換
- **事件驅動架構** - 可擴展的事件系統
- **雲端整合** - Weda EdgeSync Cloud 平台
- **簡單易用** - ASP.NET Core 風格框架
