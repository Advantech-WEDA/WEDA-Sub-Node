# 事件系統

> 透過事件驅動機制在資料處理流程中插入自訂邏輯。

## Overview

SubNode SDK 提供事件驅動的擴展機制，讓開發者可以在資料處理流程的關鍵節點插入自訂邏輯，例如：原始資料監控、閾值告警、本地儲存等。

## What You'll Learn

閱讀本文後，你將能夠：

- 理解 SubNode 事件系統的設計原則
- 掌握各事件的觸發時機與資料內容
- 在自訂 Device 中訂閱與處理事件
- 正確管理事件訂閱的生命週期
