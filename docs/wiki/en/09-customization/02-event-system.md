# Event System

> Inject custom logic into the data processing flow through event-driven mechanisms.

## Overview

SubNode SDK provides event-driven extension mechanisms that allow developers to inject custom logic at key points in the data processing flow, such as: raw data monitoring, threshold alerts, local storage, etc.

## What You'll Learn

After reading this article, you will be able to:

- Understand the design principles of the SubNode event system
- Master the trigger timing and data content of each event
- Subscribe to and handle events in custom Devices
- Properly manage event subscription lifecycle
