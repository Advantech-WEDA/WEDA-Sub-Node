# 內部範例

此目錄包含使用真實研華裝置的內部測試範例。

**⚠️ 重要提醒**：此目錄及其內容**不包含在公開的 `develop` 分支中**。僅存在於內部分支，供研華內部測試與開發使用。

## 內容

- **wise-4012/** - WISE-4012 裝置整合範例
- **wise-4012-isensing/** - WISE-4012 搭配 iSensing 模組整合範例

## 分支策略

- `develop` 分支：**不包含**此 `internal/` 目錄
- `internal` 或 `advantech-internal` 分支：包含此目錄

## 用途

這些範例展示與真實研華硬體裝置的整合，用於：
- 內部測試與驗證
- 硬體相容性驗證
- 客戶參考實作（需簽署保密協定）
- 生產環境部署範例

## 新增內部範例

新增內部裝置範例時：
1. 在 `internal/` 下建立新的子目錄
2. 遵循命名慣例：`{產品線}-{型號}/`
3. 在每個範例中加入 README.md 說明硬體設定
4. 確保範例僅提交到內部分支

## 保密性

**請勿**將此目錄合併到公開的 `develop` 分支。
